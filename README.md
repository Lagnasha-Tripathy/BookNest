# BookNest - AI-Powered Library Chatbot

BookNest is an AI-powered library management chatbot designed to make library interactions simpler and more conversational.

The chatbot helps users explore books, get book recommendations, manage borrower-related information, and interact with the library system through a natural-language interface.

## Features

- AI-powered conversational chatbot
- Book catalog search
- Book recommendations based on user queries
- Library and book-related assistance
- Borrower information management
- Natural-language interaction
- Streamlit-based user interface
- Integration with Google's Gemini API
- Simple CSV-based book and borrower data management

## Tech Stack

- **Programming Language:** Python
- **Frontend / UI:** Streamlit
- **AI Model:** Google Gemini API
- **Data Storage:** CSV
- **AI Concepts:** Prompt Engineering, Conversational AI, Recommendation System
- **Development Tools:** Git, GitHub
